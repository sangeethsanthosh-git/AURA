# Welcome to AURA Personal Knowledge

AURA can index your local project notes, documents, and code files.

## Key Features
- Fast local search with zero cloud upload
- Supports Markdown (.md), Text (.txt), JSON (.json), and Code files (.py, .ts, .js)
- Ask questions like: 'What did my notes say about database setup?'

## Project Guidelines
The AURA project runs on Windows 11 with an RTX 2050 GPU and Faster-Whisper CPU transcription.
