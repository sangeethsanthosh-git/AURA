# AURA Data Flow Diagrams

These files are Mermaid source files. Open them directly in VS Code with the Mermaid extension installed.

## Files

- `DFD_Level_0.mmd` - Context-level DFD
- `DFD_Level_1.mmd` - Current backend data flow
- `DFD_Level_2.mmd` - Smart Router internal data flow
- `Future_DFD.md` - Future Electron, React, SQLite, RAG, and plugin flow

## How to Preview

1. Open any `.mmd` file in VS Code.
2. Use the Mermaid preview command from the extension.
3. Export as PNG/SVG if your extension supports export.
